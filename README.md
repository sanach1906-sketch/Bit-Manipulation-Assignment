# Bit Manipulation Assignment

## About the Project
This repository contains my Data Structures and Algorithms (DSA) assignment programs based on **Bit Manipulation in C**.

The main objective of this assignment is to understand bitwise operators and improve problem-solving skills through coding practice.

## Topics Covered
- Bitwise AND (`&`)
- Bitwise OR (`|`)
- Bitwise XOR (`^`)
- Bitwise NOT (`~`)
- Left Shift (`<<`)
- Right Shift (`>>`)
- Set Bits and Bit Counting
- Bit Masking
- XOR-based Problems
- Gray Code
- Bitwise Operations on Arrays and Numbers

## Problems
This repository contains 29 programming solutions based on LeetCode problems.

Each program is stored in a separate C file with its corresponding problem number and title.
